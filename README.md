# Library Management System

A Java-based Library Management System to manage books, members, and issue/return operations efficiently.

## Features
- Add, update, and view books
- Manage members and their details
- Issue and return books with due date tracking
- Console-based interface with input validation

## Technology
- Java 17+
- JDBC for database connectivity
- MySQL for data storage
- Console-based application

## How to Use
1. Run the `LibraryManager.java` file in your IDE.
2. Follow the on-screen instructions to add books, members, or issue/return books.
3. View reports of books and members anytime.
